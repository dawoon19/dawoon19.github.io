CONTEXT

Our team investigated how autonomous AI agents can be leveraged in collaborative design workflows and how they impact team communication or ideation processes.

We studied this using a Chrome extension sidebar interface that takes in real-time conversational audio and screenshots of whiteboards between product designers working on an ideation task together, and users can either (1) directly ask AI to provide guidance or feedback or (2) wait for automated responses from the AI based on the present context of the design conversation.

Preliminary system design involved:

GENAI FOR VISUAL & TEXT FEEDBACK

VOICE-ONLY HUMAN-AI INTERACTION

DIARIZATION FOR USER VOICE RECOGNITION

PROBLEMS

Initial usability studies revealed key UX problems in our system:

PROBLEM 1: Latency

Long delays in AI responses

  • High latencies from visual prompting + diarization

PROBLEM 2: Interaction

Low AI responsiveness

  • No indication of whether AI heard user or how much time is left for processing

PROBLEM 3: Quality

Randomness of feedback + lengthy text response

  • Many passes and branches in prompting, losing context of user question in final output

SOLUTION

Button instead of voice

>> Solves Problems 1 & 2

Voice-only interaction takes an extended amount of time due to the number of passes required: (1) AI receives audio -> (2) AI uses Whisper to transcribe audio -> (3) AI is prompted to search for instances of user summoning AI -> (4) AI proceeds with feedback processing. Per user suggestions, I dropped the voice-only interaction and created a button that sends a direct socket signal to the AI to begin processing upon the trigger. The button also shows a timer that displays the timeframe for which AI is listening to the user's feedback.

NO VISUAL PROMPTING + CONDENSE PROMPT ENGINEERING PIPELINE

>> Solves Problems 1 & 3

The original pipeline consisted of multiple passes each dedicated to a specific function (i.e. identifying the user summoning AI) with outputs being passed to the next prompt, but this caused the output to the final pass to lose the context of the user's original question. With iterations of prompts, we consolidated several passes into one prompt, and we also decided to remove the visual feedback feature (which contributed to extra prompting layers) due to users not feeling like the visuals were relevant or useful to the task even through iterations of the generative prompts. These decisions also reduced the processing time due to the removal of the visual prompting layers.

VISUAL CUES FOR AI PROCESSING

>> Solves Problem 2

I introduced a progress bar that displays the stage of processing once the AI has begun to process the audio, using backend signals for progress to UI via Web Sockets. Additionally, a countdown timer was added that tells user how much time is left before the AI begins automated feedback, addressing issues where users did not know if/when the AI heard them and whether the AI was actually processing.
